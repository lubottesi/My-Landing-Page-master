# My Landing Page

A minimal personal landing page in React: an intro line, a short description and social links, with a day/night background toggle. Content and links are set in `src/configurations.json`.

Built on top of [My-Landing-Page](https://github.com/singhkshitij/My-Landing-Page) by Kshitij Singh (MIT), customized with a new description and social links while practicing React.

**Live:** https://my-landing-page-master.vercel.app

## Stack

- React 16 (Create React App)
- react-typist (typing animation)
- CSS (separate day/night themes)

## Running locally

```bash
npm install
npm start
```

Then go to http://localhost:3000.
